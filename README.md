# Overview

This repository contains code to generate figures for the paper by Danilova et al. "Sequencing analysis reveals evidence of immune activation in advanced HER2 negative breast cancer responders treated with entinostat + nivolumab + ipilimumab".

## Input data
Most of the input data are available in the `input_data` folder. 

## Rmarkdown
The main script is `renderRmd.r` which renders Rmd files to generate html reports and output tables in the `output_data` folder. 

## Output data
The `output_data` folder will be created and will contain output tables with the analysis results.

# System requirements

The code can be run on any computer with installed the R programming environment.
